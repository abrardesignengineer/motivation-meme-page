# Motivation Meme Website

A simple motivational meme website built with HTML and CSS as part of my web development learning journey.

### What I practiced
- HTML structure using headings, paragraphs, images, and `div`.
- External CSS stylesheets and CSS selectors.
- Typography using Google Fonts (Libre Baskerville).
- CSS properties: `background-color`, `color`, `text-align`, `text-transform`, `width`, `margin`, and `border`.
- Centering content using the CSS box model.

### Tech Stack
- HTML5
- CSS3
- Google Fonts

A small project focused on practicing the fundamentals of web development through hands-on building.
